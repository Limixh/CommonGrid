Temporal recovery denemesi süreç temizliği değişikliğinden sonra tekrar çalıştırılıp geçti; buradaki kayıt son başarılı denemeden kopyalandı. Ham log/SQLite dosyaları `.local` altında kalır. Kaynaklar Git'e kopyalanmaz; kilit dosyası ile tekrar indirilebilir.

Tekrar: `npm run test:spike`, `npm run install:temporal`, `npm run spike:recovery`, `npm run spike:routing`. Raporlar bir GO kararı veya çalıştırma izni üretmez; kapsamı genişleyen testler yeni kanıt olarak ayrıca kaydedilir.

PostgreSQL kaydını tekrar üretmek için `npm run test:db`. Windows'ta hash'i sabitlenmiş proje içi geçici sunucu, CI/diğer platformda dedicated `CG_TEST_DATABASE_URL` kullanılır. Testler normal `DATABASE_URL` değerini kullanmaz. Ayrıntılar `docs/DATABASE.md` içinde.

Sandbox kanıtını tekrar üretmek için `npm run spike:sandbox`; Linux konteyner motoru gerekir. Image digest'i `spike/sandbox/image.lock.json` ile sabitlenir. İlk başarısız volume izin denemesi `.local` içinde kalır; burada son başarılı kayıt vardır. Rapor canary veya kişisel kimlik içeriği taşımaz.

Resmi CLI fixture: `npm run install:cli-fixtures` ve `npm run spike:cli-session`; mevcut Windows oturumuyla ayrı gerçek metin bağlantısı: `npm run spike:account-smoke`. İkincisi CI'a bağlı değildir. İlk başarısız Buildx/copy/CLI envanteri ve native model seçim denemeleri `.local` altında korunur. Kapsam, public binary provenance, ölçüm sınırı ve tekrar koşulları `../cli-session/README.md` içindedir.

Managed session komutları `../cli-session/MANAGED_SESSIONS.md` içinde. `coding-verifier-fixture.patch` ve `coding-verifier-literal-fixture.patch` deterministik; `managed-task-claude.patch` ve `managed-task-codex.patch` önceki gerçek AI adaylarının diff'leridir. SHA-256 değerleri ilgili raporlarla kontrol edilebilir. Yayımlanan raporlarda patch yolu yalnız bu dosya adıyla değiştirilir. Private login state, device code, credential hacmi ve makineye özel public CA/proof yayımlanmaz. Public TLS/canary token renewal yerine geçmez. CA/model profili bulguları ADR 0006'da, son sentetik kontrol/lifecycle/artifact kabulü ADR 0007'de kaydedilir.

Hesapsız son paketi tekrar üretmek için `npm run check`, `npm run install:cli-fixtures`, `npm run spike:managed-adversarial` ve `npm run spike:coding-verifier`. Başarılı CLI protokol fixture kayıtları ayrı kalır; sentetik adversarial paket gerçek model çağrısı yapmaz. Eski `.local` Git apply skip hatası dahil başarısız ve kapsamı daha dar ara koşular `.local` altında korunur; sonraki 2026-10-09 kabulü başarısız Luna görevini de kendi sonucu ile yayımlar.

Oturum sürekliliği için `npm run spike:session-continuity`; eski private profillere dokunmadan yeni sentetik kaynaklar oluşturulur ve kaldırılır. Salt okunur gerçek hesap kabulünün `--real-account [--resume]` sözleşmesi `../cli-session/MANAGED_SESSIONS.md` içindedir; CI'a eklenmez; 2026-10-09 gerçek status/restart/refresh/quota sonuçları güncel kabul kaydında ayrı tutulur. Resume checkpoint veya sayısal quota snapshot, yenileme/tükenme/izin kanıtı değildir. ADR 0008 kapsamı dar tutar.

Güncel çalışma sırası [ADR 0012](../adr/0012-go-gate-priority-and-development-boundaries.md) ve [GO listesinde](../../docs/GO_GATE.md) tutulur. İndeks tarihli kanıtı korur; yeni sayılar yalnız tamamlanmış raporlardan alınır. İşlev testlerinde Luna/Haiku tercihi eski raporların model alanlarını değiştirmez.

Yeni Haiku/Luna profilleri sonraki normal gözlemler için giriş yapmış halde korunur; önceki Sonnet/Astra profilleri logout durumundadır. Güncel görev, model, cleanup ve checkpoint sınırları [ADR 0013](../adr/0013-current-cheap-model-acceptance.md) içinde; GO verilmedi.

Araç yolu ve boş yuva bulguları [ADR 0014](../adr/0014-task-routing-and-sparse-verifier.md) içindedir. Önceki Luna adayının eski 32 vakadan geçmesi güncel 34 vaka kabulü sayılmaz; o adayın sonraki reddi korunur. Kullanıcının sonraki devam isteğiyle üretilen ayrı Luna adayı güncel 34 vaka ve patch kabulünü geçti. Haiku'nun 34 vaka replay'i ve Luna'nın yeni gerçek görevi dar görev kabulünü tamamlar; product GO kapalıdır.

Host owner ölümü ve Windows cleanup completion kanıtları [ADR 0015](../adr/0015-host-owner-crash-and-process-cleanup.md) içindedir. Başarılı açık orphan uzlaştırması otomatik production recovery olarak sunulmaz; önceki başarısız genel kontrolün sonucu değiştirilmez.

Kalıcı profil sahipliği ve command boyunca tutulmuş claim sınırı [ADR 0016](../adr/0016-durable-profile-ownership.md) içindedir. `stop()` restart boyunca claim'i tutar; `finishOperation()` namespace cleanup sonrasında kaldırır. Belirsiz create/remove sonucu otomatik takeover izni değildir.

Faz günlüğü ve salt okunur kurtarma incelemesi [ADR 0017](../adr/0017-operation-phase-journal-and-recovery-review.md) içindedir. Kayıt önce intent, sonra yakalanmış ID ve doğrulanmış receipt tutar. Eksik/bozuk günlük veya pending kayıt operator onayıyla aşılamaz. Geliştirici görünümü geçmiş kayıtları gösterir; otomatik recovery veya paketlenmiş native görev başlatıcısı değildir.
